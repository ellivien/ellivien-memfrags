# Contributing

Thank you for helping improve Ellivien MemFrags.

Before opening a pull request:

1. Keep the matching core provider-neutral.
2. Add or update tests for behavioural changes.
3. Do not include real memory libraries, conversation transcripts, credentials
   or personal information in fixtures or examples.
4. Preserve the copyright, SPDX, attribution and original-project notices.
5. Update `INSTALL-WITH-AI.md` when an integration change affects the
   non-technical installation route.
6. Run `npm test` and include the result in the pull request description.

Bug reports should include a minimal synthetic example showing the fragment,
the latest user message, the expected result and the actual result.
